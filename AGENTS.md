# Orientações para agentes

- Operar exclusivamente no repositório pessoal rvieiraborba/mercamell-promocontrol,
  com a conta rvieiraborba. Nunca utilizar a conta profissional rafael-borba_LGGIT.
- Seguir CONTRIBUTING.md. Criar uma branch por mudança concreta:
  feature/ ou fix/ a partir de develop, hotfix/ a partir de main.
- Não criar branches vazias para correções inexistentes.
- Propor alterações por PR; preservar main como código final homologado.
- Não fazer push direto em main/develop, force push, reset destrutivo ou
  sobrescrever alterações de outras pessoas.
- Não publicar bancos, backups reais, dados pessoais ou segredos.
- Executar as verificações pertinentes e relatar o que foi efetivamente validado.
